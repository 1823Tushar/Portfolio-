# Developer Portfolio

A responsive, mobile-first portfolio built with semantic HTML5, CSS Grid/Flexbox and vanilla JavaScript.

**Live site:** https://your-username.github.io/portfolio/

## Features
- Sections: Hero, About, Skills grid, Featured projects, Contact
- Dark / light theme toggle (remembers your choice, respects system setting)
- Mobile hamburger menu and smooth-scroll navigation
- Project modal popups driven by a simple JavaScript array
- No build step, no dependencies

## Run locally
Open `index.html` in a browser, or run `npx serve .`

## Customize
1. Replace "Your Name", email and social links in `index.html`
2. Edit the `projects` array at the top of `script.js`
3. Add `resume.pdf` to the project root

## Deploy
Hosted free on GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/root`).
